# devops-infinity Homebrew tap agent instructions

Instructions for an AI agent working in this repository. `CLAUDE.md` and `AGENTS.md` carry identical text under two names, so every tool finds the rules under the name it looks for. Change one and copy it to the other in the same run.

## What this repository is

This is a Homebrew tap. `Formula/` holds one formula per tool: `ownpg.rb`, `ownsearch.rb`, and `ownserp.rb`, each naming a published release of its tool. `README.md` carries the install commands, `SECURITY.md` the security policy, and this file and `AGENTS.md` the agent rules. This file does not restate the install commands.

## Do

- Edit `README.md` and `SECURITY.md` by hand when asked to change this repository's own documentation.

## Don't

- Don't hand-edit `Formula/ownpg.rb` once it exists. It is generated by the `ownpg` repository's release tooling from the actual release artifacts, and a hand edit is overwritten on the next release.
- Don't reconfigure GitHub's private vulnerability reporting on this repository. It is already enabled.
