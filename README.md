# devops-infinity Homebrew tap

Homebrew formulas for the devops-infinity tools.

```sh
brew tap devops-infinity/tap
brew install ownpg
```

The `ownpg` formula lands under `Formula/` with the first release of `ownpg`. Until then this tap carries no formula. Bug reports for `ownpg` go to https://github.com/devops-infinity/ownpg-releases/issues.
